# Greenhouse Gas Emitter Check

Search EPA-reported greenhouse gas emissions by facility name, parent company, or ZIP code. Browse by state. See gas breakdowns, 5-year trends, and national rankings.

**Live site:** https://GreatTombProductions.github.io/greenhouse-emissions/

## What this is

A search tool for the EPA Greenhouse Gas Reporting Program (GHGRP) data. Covers 8,700+ facilities that report 25,000+ metric tons of CO₂ equivalent per year — power plants, refineries, chemical plants, landfills, and more.

## What this isn't

- Not an advocacy tool
- Not real-time monitoring
- Not a complete emissions inventory (smaller facilities don't report)

## Data Source

EPA Greenhouse Gas Reporting Program (GHGRP), via the Envirofacts API. Annual reporting data, 2019-2023. All emissions in metric tons of CO₂ equivalent.
